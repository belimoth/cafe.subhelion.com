# Requirements

- Bash (included in Git for Windows)
- Python 3
- Visual Studio Code or equivalent

# Development

with system (zach)

```sh
edit  cafe.subhelion.com
```

with system

```sh
code-clone subhelion/cafe.subhelion.com
code-edit  subhelion/cafe.subhelion.com
```

without system

```sh
git clone git@github.com:subhelion/cafe.subhelion.com.git
cd cafe.subhelion.com
code .
```

# Development Scripts

```sh

# installing
install

script/develop/submit
```
